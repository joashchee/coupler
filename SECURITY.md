# Security

Please report security problems privately, not in a public issue: use
GitHub's **Report a vulnerability** button on this repository's
Security tab.

Things that count as security problems in Coupler include:

- anything that makes Coupler connect anywhere but CoffeeMUD's own
  hosts, or fetch anything from elsewhere;
- a password shown, logged, kept in history or written to a file;
- game data (the journal, the hooks, maps, other players' names and
  chat) leaving the player's computer;
- a crafted message from the game server that crashes Coupler, reads
  or writes files outside Coupler's own app-data folder, or runs code.

You'll hear back within a week. Fixes go in the next release, with
credit if you'd like it.
